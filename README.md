A tiny deterministic program that writes one funny line to `/output/entry.txt`. The joke turns a failed attempt at low-maintenance houseplants into a confession of guilt toward the plastic replacements.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. The entry is written to `/output/entry.txt` (103 characters, within the 1–200 gate).
